<h1>⚽ Tabelas de Ligas de Futebol Famosas</h1>

<p>
  Este projeto exibe as <strong>tabelas classificatórias de ligas de futebol</strong> famosas ao redor do mundo. Ideal para acompanhar a posição dos times em campeonatos nacionais e internacionais de forma simples e visual.
</p>

<h2>✨ Funcionalidades</h2>
<ul>
  <li>Exibição de tabelas por liga</li>
  <li>Informações atualizadas sobre posições, pontos e desempenho</li>
  <li>Layout limpo e responsivo</li>
</ul>

<h2>🚀 Tecnologias utilizadas</h2>
<ul>
  <li><strong>Javascript</strong></li>
  <li><strong>HTML</strong></li>
  <li><strong>CSS</strong></li>
</ul>
